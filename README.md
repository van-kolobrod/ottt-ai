# ОТТТ-ИИ

**ОТТТ: онтология — топология — технология — телеология.**

Исследовательский проект по представлению знаний, обнаружению закономерностей, управлению вниманием, выбору действий и проверке результата в гибридных интеллектуальных системах.

**Статус на 14 ноября 2026 года:** существуют отдельные экспериментальные механизмы на Python и рабочие архитектурные гипотезы. Единой работающей архитектуры ОТТТ-ИИ, универсального метаоператора и обученной на принципах ОТТТ нейросети в репозитории **нет**. Не смешивать работающий эксперимент, согласованное определение, гипотезу и план.

## Начать отсюда

1. [Исследовательский статус](docs/RESEARCH_STATUS.md) — что реализовано, что проверено по текстам и что ещё не сделано.
2. [Ориентирование, четыре аспекта, фокус и полнота фокуса](docs/OTTT_ORIENTATION_AND_FOCUS.md) — основная рабочая схема метаоператора.
3. [Память, познание и программа экспериментов](docs/COGNITIVE_MEMORY_AND_EXPERIMENTS_2026-11-09.md) — проектируемая внешняя память, исследование и критерии сравнения.
4. [ОТТТ-ориентированная нейронная архитектура](docs/OTTT_ORIENTED_NEURAL_ARCHITECTURE_2026-11-09.md) — альтернативные варианты A/B/C; гипотеза, не реализованная модель.
5. [Граф знаний и рассуждение](docs/architecture/GRAPH_KNOWLEDGE_AND_REASONING.md) — предложенная форма организации знаний, ещё не выбор СУБД.

Эти документы задают **текущий исследовательский фокус**, но не являются доказанной теорией интеллекта. Четыре аспекта ОТТТ не обязаны означать четыре физически независимые базы или нейросетевые подсистемы.

## Рабочие вычислительные эксперименты

- `experiments/discovery*.py` — ограниченный поиск формул и перенос отношений;
- `experiments/memory/` — событийная SQLite-память, интерпретация признаков, ASCII-восприятие, исследовательское внимание, проверка числовых гипотез, сопоставление объектов во времени и подбор порогов;
- `data/` — подключаемые JSON-словари;
- `tests/` — автоматические тесты этих механизмов.

Запуск из корня репозитория:

```bash
python -m unittest discover -s tests -v
python -m unittest experiments.discovery experiments.discovery_symbolic experiments.discovery_transfer -v
```

Наличие тестов не означает, что каждый новый просмотр документации повторно проверял их выполнение. Описание воспроизводимых опытов: [исследовательское внимание](docs/RESEARCH_ATTENTION.md), [числовой цикл](docs/RESEARCH_CYCLE.md), [идентичность](docs/ENTITY_IDENTITY.md), [обучение критериям идентичности](docs/IDENTITY_LEARNING.md).

## Дополнительные исследовательские заметки

В `docs/` и `docs/architecture/` остаются онтология, элементарное действие, познавательный цикл, композиция, метаотношения, социальная телеология и другие направления. Это **источники гипотез и решений по отдельным вопросам**, а не обязательные этапы реализации. См. [журнал разработки](docs/DEVELOPMENT_LOG.md).

## Следующая инженерная задача

Проверить на одной ограниченной задаче, даёт ли внешний цикл **ориентация → постановка цели → фокус → уточнение → выбор действия → проверка** измеримую прибавку к обычной LLM с теми же инструментами и бюджетом. До такой проверки нельзя утверждать, что архитектура ОТТТ эффективнее известных подходов.
