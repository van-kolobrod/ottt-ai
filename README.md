# ОТТТ

**Онтология — топология — технология — телеология.**

Учебно-исследовательский проект: описание устройства мира и целенаправленного действия через четыре аспекта одной модели.

- **Онтология** — что есть: сущности, свойства, уровни систем.
- **Топология** — как это связано: отношения, структура, причинность.
- **Технология** — как это изменить: последовательности действий, переводящие одно состояние в другое.
- **Телеология** — что нужно: цели, критерии желаемого состояния, направленность.

Сейчас проект — это тексты. Реализации ОТТТ в коде нет; ранние вычислительные опыты лежат в [архиве](archive/README.md).
